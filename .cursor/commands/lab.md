---
name: lab
description: Open the Veyra laboratory Workbench
---

Call `lab_status`. If the HTTP laboratory is down, call `start_laboratory` (starts the Workbench without the VS Code extension). Then give them http://127.0.0.1:8765/. Command Palette → **Veyra: Open Laboratory** is the same URL when the extension is installed. Do not invent scientific numbers.
