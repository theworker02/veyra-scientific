Veyra Scientific

Don't guess the science. Run it.

A real local Workbench capture. Numeric results come from the Python kernel.

Veyra is a Cursor-native computational laboratory. Define an experiment, validate its dimensions, execute it locally, and preserve the graph, methods, diagnostics, and evidence behind every result. Agents present kernel output; they do not invent numeric results.

Source Cursor Directory

Install

  1. Install the Cursor plugin from Directory, Marketplace, or this repository.
  2. Reload. First use installs the kernel from this checkout and packages the optional Workbench extension when needed.
  3. Ask the Agent for start_laboratory, or use Command Palette → Veyra: Open Laboratory.

The Workbench is served even if the activity-bar extension is not installed. Full finite-element analysis is outside the current scope.
